# BLOCKVERSE — Unity Edition

- Engine: Unity 6.0.60f1
- Language: C#
- Target: Android
- Package: `com.dev.blockverse`
- Orientation: Portrait

## Current foundation

- Grid board model with placement validation.
- Full row/column clearing, including 2-hit ice obstacles and stone obstacles.
- Deterministic procedural level configuration with regular, move-limited, score-trial, and boss goals.
- Starter piece shape library.
- Editor menu command that creates a basic starter scene and sets Android identity/build scene.

## Create the first scene

Open this folder in Unity 6.0.60f1, allow scripts to compile, then choose **BLOCKVERSE → Setup Starter Scene**. Open `Assets/Scenes/Game.unity` and press Play.

The initial scene is a development scaffold. Drag-and-drop gameplay, tray generation, progression screens, effects, audio, saving, and monetization are subsequent implementation stages.

## Build

Use the repository workflow **BLOCKVERSE Unity Android** after adding the Unity licensing secrets described in the repository README.
