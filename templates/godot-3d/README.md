# Godot 3D starter

Create a new Godot 4.x project here or copy this folder into `projects/<game-name>`.

Suggested initial structure:

```text
project.godot
scenes/
  main.tscn
scripts/
  main.gd
assets/
export_presets.cfg
```

Recommended starting settings:
- Use Mobile renderer for a mobile-focused 3D game; profile on real Android devices.
- Keep materials, lights, shadows, and polygon counts appropriate for target devices.
- Configure touch controls and safe-area-aware UI.
- Create an Android export preset named `Android`.

This folder is a guide only; it is not yet a runnable Godot project.
