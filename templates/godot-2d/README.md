# Godot 2D starter

Create a new Godot 4.x project here or copy this folder into `projects/<game-name>`.

Suggested initial structure:

```text
project.godot
scenes/
  main.tscn
scripts/
  main.gd
assets/
export_presets.cfg
```

Recommended starting settings:
- Renderer: Compatibility for broad Android device support, unless the game needs features from another renderer.
- Orientation: choose portrait or landscape intentionally.
- Input: configure touch controls and test different screen sizes.
- Android export: create an export preset named `Android`.

This folder is a guide only; it is not yet a runnable Godot project.
